# 💼 Portfólio Paulo Sérgio (psgs)

Portfólio pessoal desenvolvido com **React + Vite**, apresentando projetos, habilidades e experiências profissionais.

## 🚀 Tecnologias

- **React 18.3.1** - Biblioteca JavaScript para interfaces
- **Vite 5.4.2** - Build tool e dev server
- **Font Awesome 6.0.0** - Ícones
- **Google Fonts** - DM Sans & Poppins

## 🔧 Instalação e Uso

### Pré-requisitos
- Node.js 16+ instalado
- npm ou yarn

### Passos

1. **Clone o repositório**
```bash
git clone <url-do-repositorio>
cd portfolio/portfolio-react
```

2. **Instale as dependências**
```bash
npm install
```

3. **Inicie o servidor de desenvolvimento**
```bash
npm run dev
```

4. **Acesse no navegador**
```
http://localhost:5173
```

5. **Build para produção**
```bash
npm run build
```

## 🎨 Seções do Portfólio

1. **Header** - Navegação fixa com tema toggle

8. **Contact** - Formulário e informações de contato
